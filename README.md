# PillVision

PillVision is a senior design project focused on developing a
computer vision-based pill counting and verification system.

The project will investigate methods for accurately counting pills
under realistic conditions, including touching and partially
overlapping pills. Controlled minimal vibration may be used to reduce
severe clustering, while computer vision algorithms will handle
remaining overlap and identify visually inconsistent pills.
